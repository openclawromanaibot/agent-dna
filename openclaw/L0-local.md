# OpenClaw root routing

The active OpenClaw workspace contains the single injected AGENTS.md, assembled from verified Agent DNA. Do not edit it to store lessons or local fixes.

Before acting, identify all matching classes below, open each matching `instructions/<class>/index.md`, then follow its referenced skill. Read files with the read tool; do not assume a path reference means its contents were injected. Subagents must follow the same routing process.

| Class | Open when the task involves |
| --- | --- |
| comms | Messages to other agents, email, external parties and channels |
| code | Code, branches, pushes, pull requests and CI |
| secrets | Credentials, tokens, keys and authentication failures |
| memory | Session start, shared knowledge, memory and daily logs |
| shell | Any host command: git, node, npm, scripts or exec |
| automation | Scheduled jobs, watchers and recurring scripts |
| ops | Session start, status, progress, mistakes and cleanup |
| jobsearch | Vacancies, applications, job-search pipelines and reports |

If no class or procedure fits, stop and ask. The extra operational guardrails are included below in the same AGENTS.md from `openclaw/instructions/root-operations.md`. Local environment facts remain in `instructions/FACTS.md`.
